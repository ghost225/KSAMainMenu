# Changelog

## 0.1.0 (2026-11-06)

First release.

- Title screen over your home world from orbit, with Hunter, Banjo and Polaris floating in front of it.
- World picker before KSA loads, with each world's last save and a countdown to the last world played.
- Continue, New Game (in place, no restart), Load Game (with Delete), Settings, Mods, Menu Options, Credits, Quit.
- Saves load only into worlds that have all their planets; otherwise the menu switches worlds.
- MAIN MENU in the pause menu and a Game tab in the top menu bar.
- New loading screen: slideshow, logo, and an orbiting-rocket loading icon beside KSA's progress.
- On Linux, switching worlds restarts KSA by itself (this also fixes KSA's own Restart button under StarMap). Elsewhere the menu asks you to start KSA again.
